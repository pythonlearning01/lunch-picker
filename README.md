# 今天吃什麼？

一個以手機瀏覽器為主的餐廳口袋名單與抽籤小工具。

## 使用方式

將這個資料夾放到支援 HTTPS 的靜態網站空間後，以手機瀏覽器開啟網站，再使用瀏覽器的「加入主畫面」功能。網站可安裝為獨立視窗，並會快取介面供離線開啟。

在電腦本機預覽時，可於此資料夾啟動簡易伺服器：

```powershell
python -m http.server 8000
```

接著用瀏覽器開啟 `http://localhost:8000`。主畫面安裝及離線快取需透過 HTTPS 網站（本機 localhost 除外）。

## 資料與功能

- 餐廳資料保存在目前瀏覽器的本機儲存空間，不會傳到伺服器。
- 可新增、編輯、刪除餐廳，並匯出或匯入 JSON 備份。
- 每家餐廳可設定多種類型、人均價格，以及冷氣、飲料、湯、汽車停車。
- 抽籤會依條件篩選後，隨機抽出最多三家互不重複的餐廳。
- 預設類型：中式、日式、西式、泰式、火鍋、鐵板燒、速食、自助餐、粥。
